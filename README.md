# 🔧 Taller Pro — Enterprise Edition

Sistema premium de gestión de talleres mecánicos.  
Diseño de alto nivel, animaciones, datos de demostración y sección de tutoriales en video.

## Características

- Dashboard en tiempo real con estadísticas animadas
- 7 vehículos de demostración precargados
- Registro de entradas, cambios de área y salidas
- Historial completo de movimientos
- Sección de tutoriales con videos
- Diseño glassmorphism + animaciones suaves
- Exportar / Importar backup JSON
- 100% estático → perfecto para GitHub Pages

## Cómo publicar en GitHub Pages

1. Crea un repositorio público (ej: `Pagina-web` o `taller-pro`)
2. Sube estos 3 archivos a la **raíz** del repositorio:
   - `index.html`
   - `styles.css`
   - `app.js`
3. Ve a **Settings → Pages**
4. Source: rama `main` / carpeta `/ (root)`
5. Espera 1-2 minutos y abre la URL

**Importante:** Los 3 archivos deben estar en la raíz, no dentro de una subcarpeta.

## Uso

- La primera vez verás un modal de bienvenida y datos de ejemplo.
- Explora el Dashboard, mueve vehículos, marca salidas.
- Ve a **Tutoriales** para los videos explicativos.
- Configura tus áreas y personal reales en Configuración.
